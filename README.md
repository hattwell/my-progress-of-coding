# My Progress of Coding

Учебный многостраничный сайт, в котором я фиксирую свой путь в веб-разработке, изученные темы и созданные проекты.

Историю развития сайта можно посмотреть по коммитам в репозитории.

## Цель проекта

Изучить frontend-разработку, собрать портфолио и подготовиться к прохождению стажировки в Яндексе.

## Как открыть проект локально

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта.
3. Открыть файл `index.html` в браузере.

## Текущий статус

Сейчас проект находится на этапе изучения HTML. Стили, адаптивная верстка и интерактивность будут добавляться по мере изучения новых технологий.
